# 設計決策

本文件記錄會影響相容性、安全性與後續維護的重要取捨。狀態分為「採用」與「待評估」。

## DD-001：Android 12+ 為最低平台（採用）

使用 `BLUETOOTH_SCAN` 與 `BLUETOOTH_CONNECT` 的新權限模型，避免把 BLE 掃描包裝成定位功能。代價是 Android 11 以下裝置不在支援範圍。

## DD-002：裝置直連，不設預設雲端（採用）

核心功能全部在手機與裝置之間完成。App 不要求帳號，也不內建 API endpoint 或憑證，降低服務停止與個人資料外流風險。

## DD-003：所有 GATT 操作共用單一 FIFO（採用）

Descriptor write、characteristic read 與 write 必須等待各自 callback 才完成。這會犧牲少量初始化速度，但可避免 Android BLE stack 因並行操作遺失工作。

## DD-004：控制後重新讀取狀態（採用）

SET 命令送出後約 750 ms 再發送 GET ALL。畫面最終以裝置回報為準，不預先假設控制一定成功。

## DD-005：Auto 與 Turbo 採不同狀態（採用）

目前風量使用 ID 506；其中值 `8` 代表 Auto。Turbo 使用 ID 863 的獨立布林狀態。介面不得以 Turbo 覆蓋原始風量，也不得把 ID 531 顯示成風量 Auto。

## DD-006：關閉電源需要二次確認（採用）

遠端關閉後可能無法再由 App 喚醒裝置，因此開啟動作可直接執行，關閉則顯示風險說明與確認視窗。

## DD-007：裝置版本只讀標準欄位（採用）

實機只在 Device Information service 的 Software Revision 提供可信版本值，因此 App 僅讀取並顯示「裝置版本」。其他欄位不是未提供，就是內容與 Bluetooth SIG 欄位語意不符，不呈現在 UI 或匯出資料中；版本 characteristic 缺少時顯示「裝置未提供」。

## DD-008：外觀設定保存在 App 私有偏好（採用）

提供跟隨系統、淺色與深色，使用 `SharedPreferences` 保存。配色使用 Material 3 語意色，避免功能元件依賴固定淺色背景。

## DD-009：背景連線採能力揭露，不假裝支援（採用）

背景連線以 Foreground Service、常駐通知與有限退避重連實作。依距離自動開關需要連線狀態能隨手機距離變化，兩者因此使用單一 `ConnectionMode` 互斥保存；開啟其中一項會關閉另一項。距離模式與不同品牌的省電策略仍列為實機驗證範圍。

## DD-010：空氣品質感測器 timing 使用裝置端設定（採用）

ID 823 的 `0` 表示「當產品開啟時」，`1` 表示「始終開啟」。UI 使用兩個明確單選項；選擇始終開啟前提示額外耗電與運轉聲，不以模糊的布林開關呈現。

## DD-011：高風險命令不納入第一版（採用）

濾網重設、Firmware 寫入及其他無法輕易復原的操作不提供 UI，也不由一般狀態流程觸發。

## DD-012：濾網百分比採裝置總時數並提供相容性備援（採用）

優先以 ID 853 的剩餘時數除以 ID 854 的總時數計算，採整數百分比；剩餘時數大於零但結果不足 1% 時顯示 1%。部分回報可能缺少總時數，此時以 2,000 小時作為備援。數值會限制在 0–100%，避免異常回報破壞進度顯示。

## DD-013：濾網提醒採可選門檻與每週期一次通知（採用）

使用者可以關閉提醒，或選擇剩餘 3%、5%、10%、20% 為門檻。讀值達到或低於門檻後只通知一次；壽命回升至門檻以上視為新濾網週期，才允許再次通知。Android 13 以上只有在使用者啟用提醒時請求通知權限，不把提醒權限與背景連線設定綁在一起。

## DD-014：未回報值與本機暫存值必須明確揭露（採用）

裝置未提供濾網總時數時，UI 明示「未回報，暫以 2,000 小時計」，不把相容性備援呈現成裝置資料。指示燈亮度若未出現在完整狀態回報，只保留本次連線的最後設定值；GATT 寫入失敗或逾時時回復設定前狀態，重新連線後回到「尚未設定」。

## DD-015：外部整合採選配 bridge，讀取與命令權限分離（待評估）

未來若加入本機歷史、Smart Home 或研究整合，狀態與 outbox 應在同一 SQLite transaction 建立，再由手機主動同步至使用者設定的 HTTPS bridge；Android App 不預設長期開放 HTTP server。bridge 的唯讀 API 使用 read-only token，Touch 等具副作用命令使用獨立 command token、到期時間、冪等鍵、速率限制及執行回報。所有外部連線預設關閉，公開 build 不內建 endpoint 或 credential。
