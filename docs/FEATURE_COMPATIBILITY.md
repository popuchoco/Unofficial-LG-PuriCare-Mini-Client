# 功能相容性對照

## 裝置資訊選單

既有流程中的裝置資訊頁包含下列入口：

| 項目 | 實際用途 | PuriCare Mini Next |
|---|---|---|
| 裝置名稱 | 顯示及修改 App 內名稱 | 顯示連線名稱；尚未提供改名 |
| 濾網管理 | 查看濾網並進入重設流程 | 顯示剩餘百分比、剩餘／已用／總時數，支援 3%／5%／10%／20% 更換提醒；不提供重設 |
| 空氣品質感測器 | 選擇感測器運作 timing | 已提供相同兩項選擇 |
| 自動開啟與關閉 | Bluetooth 距離或充電線供電 | 目前只提供 Bluetooth 距離模式 |
| 清淨顯示燈 | 支援機型的亮度級距 | 目前提供開／關 |
| 軟體版本 | 顯示既有 App 自身版本 | 分開顯示新版 App 版本與裝置實際提供的版本 |

既有資訊頁沒有顯示可驗證的裝置 Manufacturer、Model、Firmware 或 Hardware revision，因此新版不建立這些空白或語意錯置的欄位。

## 空氣品質感測器 timing

裝置端使用 ID 823：

| 值 | 選單文案 | 行為 |
|---:|---|---|
| `0` | 當產品開啟時 | 只在產品運轉時啟用空氣品質感測器 |
| `1` | 始終開啟 | 關機狀態仍持續感測，會增加耗電與運轉聲 |

選擇「始終開啟」前需要額外確認。

## 自動開關與背景連線

Bluetooth 距離自動開關使用 ID 531 的值 `1`。裝置預期依手機與產品的連線狀態開啟或關閉，但仍待更多手機、距離及關機狀態的實機驗證。背景連線會維持並恢復 BLE，兩者目標互相衝突，因此 App 使用單一連線模式保證只能選擇一項。

充電線供電自動開關對應值 `2`，兩種自動條件同時啟用為 `3`。目前版本尚未提供這兩項，待實機確認充電狀態與關機後行為後再評估。
